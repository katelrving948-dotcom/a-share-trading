# A股周度趋势与风险系统

系统面向小资金趋势波段交易。三个入场条件必须同时满足：**基本面合格、上升趋势、回调企稳**。市值初筛下限为20亿元；中小市值保留扫描名额，但不会绕过基本面、趋势、板块或账户风险条件。模拟仓用同一套选股与开仓规则前向运行，研究排行不等于交易许可。

## 启动网站

```bash
pip install -r requirements.txt
python server.py
```

访问 `http://localhost:5000`。网站包含：

1. **概览**：数据日期、风险状态、本周候选与计划/持仓入口；私密金额在解锁后显示。
2. **计划**：账户风险档位、2只主选/1只备选、目标股数上限、禁追、止损、止盈和国际事件三情景。
3. **持仓**：解锁后查看已保存持仓与午间建议；导入截图在独立页面按“上传 → 核对 → 保存”操作。切换页面保留草稿，离开网站时提醒未保存修改。
4. **研究**：基本面评分、板块资金、核心观察、研究池、美股行情和新闻快讯按分类查看。美股展示道琼斯、标普500、纳斯达克综合指数；新闻分地缘局势与国内金融，支持摘要展开及原文链接。手机端研究表格显示为可展开卡片，每页10项，可查看完整字段。
5. **更多**：双模式模拟仓、任务控制和系统规则。手机使用底部导航，电脑使用侧栏；原 `/#push`、`/#fundamental`、`/#paper` 链接继续可用。

## 周度规则

- 每周一12:00生成计划，周内使用同一 `plan_id`；名单只允许撤销，不因日度排行变化新增股票。
- 每周最多2只主选、1只备选；不满足条件时允许少于3只或空仓。
- 周度分为基本面40%、中期趋势30%、板块15%、国际事件敏感度10%、估值/拥挤度5%。中期趋势直接使用日K/周结构和沪深300相对强度，不读取量化优化分数。
- 原始基本面与行业校准分均须≥60，板块≥55且无财务硬风险。20日均线上行并高于60日均线、价格高于60日均线、相对基准走强，才能进入趋势观察。过热股票可等待回调，不直接买。
- 固定支撑区为计划形成时MA20±0.5ATR；从已知近10日高点回撤至少1ATR并触及支撑后，等待后续完整日K低点不再降低且收盘回到支撑上沿之上。不得用当日未完成日K确认。
- 最早确认后的下一交易日，使用当日5分钟内分时价检查买入区、4%-7%结构风险距离、到已知前高至少1.5R空间及账户风险。超过最高价、破位、过期或数据缺失都不许可；突破路径关闭。
- 每只候选给出回调支撑、最高买价、失效价和持仓观察期：500亿元以下3-10个交易日，较大市值5-20个交易日；从实际买入日起计，3/5日未恢复强势则复核退出，破位提前退出。未录入买入日时不虚构持仓天数或具体卖出日期。
- 回调价位在周度计划内固定，后续5个有效日K内跟踪，失效或到期不自动下移支撑。详见 [回调策略规则与验证](docs/pullback_strategy.md)。

## 账户风险

账户状态保存在已忽略的本地文件 `output/research/account_state.json`；字段模板见 `docs/account_state.example.json`。网站支持手动填写持仓，或把券商截图发送至阿里云百炼通义千问视觉模型生成待确认草稿；网站不保存原图，识别结果必须人工确认后才能保存。生产邮件从私密 `ACCOUNT_STATE_JSON` 读取确认后的账户和逐股持仓。核心字段：

```json
{
  "equity": 50000,
  "available_cash": 50000,
  "last_week_pnl": -3500,
  "last_week_end": "2026-08-21",
  "current_week_pnl": 0,
  "market_state": "普通"
}
```

- 上周亏损达到2%后，下一周进入恢复期：总仓30%、单股15%、单笔风险200元。
- 普通期总仓最高60%、单股20%、单笔风险300元；强势期最高70%。
- 本周亏损达到2%立即停止新增风险。
- 单笔风险取当前档位金额与账户净值0.6%的较小值；按实际复核价（缺失时用最高买价）到失效价的距离计算股数，并受单股、总仓及现金上限约束。普通股票100股整数倍，科创板至少200股。
- 计划股数是该股票的目标持仓上限，不是忽略现有仓位后的追加买入量；执行前需要自行确认账户总仓位不超过当前档位上限。

账户接口均需 `Authorization: Bearer <CRON_SECRET>`：`GET/POST /api/account` 读取或更新账户，`POST /api/account/extract` 识别截图草稿，`GET /api/account/analysis` 返回私密持仓和午间建议。公开 `/api/push/preview` 不返回资金、盈亏、成本、数量或持仓动作。截图识别需要 Render 私密环境变量 `DASHSCOPE_API_KEY`；`DASHSCOPE_VISION_MODEL` 默认 `qwen3-vl-plus`，中国大陆默认接口为 `https://dashscope.aliyuncs.com/compatible-mode/v1`，使用业务空间专属地址时可通过 `DASHSCOPE_BASE_URL` 覆盖。保存时会尝试用 `GITHUB_ACTIONS_TOKEN` 更新仓库加密 Secret `ACCOUNT_STATE_JSON`，供下一次邮件任务读取；令牌权限不足时页面会明确显示仅保存到当前 Render 实例。

## 每日推送链路

`.github/workflows/daily-stock-email.yml` 在工作日04:00 UTC（北京时间12:00）运行。任务先刷新前一交易日复盘和当日09:30-11:30上午行情，再读取已确认持仓；周度名单仍只在周一生成并于周内冻结：

`GitHub Actions → 前一交易日与上午行情研究 → 私密持仓分析 → 冻结weekly_plan.json → 一封合并邮件`

上午行情采集和质量检查完成后，午间任务将公开页面数据保存为 `output/research/website_snapshot.json` 并发布到仓库。页面直接读取保存的快照，后台检查更新，不因打开页面重新抓取和计算行情。快照显示采集时间；休市或采集失败时保留最近一次成功结果，交易前仍需复核实时行情。首次尚无快照时提示等待午间采集。账户和持仓私密字段不会写入该公开快照。

板块资金、核心观察、研究池和计划共用页面快照；基本面、美股和新闻各读自己的快照。浏览器仅保存这三个公开研究接口的上次成功结果，再次打开先显示本机数据，后台检查服务器更新，20秒未响应会明确提示并保留旧内容。本机存储不可用时仍可读取服务器。历史日期标注“非今日交易建议”；私密账户接口不进入浏览器快照缓存。Render免费实例休眠后的首次页面请求仍可能慢，后端快照消除了行情采集带来的额外等待。

邮件生成后将同一份 `weekly_plan` 保存给网站读取，不各自计算仓位或交易许可。`dispatched` 只说明工作流已触发，不等于收件箱已收到。

## 美股行情与新闻快讯

`.github/workflows/market-news.yml` 每小时第17分钟采集新闻，周末和节假日照常运行；GitHub Actions 调度可能延迟，页面以实际采集时间为准。此任务不发送邮件，也不受A股交易日和邮件质量检查限制。

`python news_snapshot.py` 使用东方财富快讯栏目，按关键词筛选最近72小时的地缘局势、国内金融和美股市场消息；分类是信息整理，不推断利好利空。每个分类分别记录成功更新时间，源失败或无有效内容时保留上次成功内容并标注；超过2小时未更新时页面提示。默认每次显示10条，新闻页可查看更多。

美股数据来自腾讯财经三大指数。按 `America/New_York` 时区判断收盘，在16:15之后的小时任务中采集，兼容夏令时；同一交易日成功保存后不再刷新。休市、数据不完整或日期混杂时保留最近成功快照。行情源时间早于15:55时无法确认常规收盘，不覆盖旧数据；提前收市日需要另行复核。页面区分美股交易日、北京采集时间与行情源时间；收盘后快照属于研究参考。

独立公开快照保存于 `output/research/market_news.json`，`GET /api/research/news` 只读取缓存，后台同步仓库快照；刷新按钮也只读取快照，不重新采集。首次没有快照返回503，新闻接口不依赖午间页面快照。新增内容不参与基本面评分和交易许可，午间邮件保留原有外盘与事件分析。

午间邮件已移除量化评分、回测表现、优化日志及量化快照发送前置条件，保留原有行情完整性检查。邮件提供双模式模拟仓入口；12:00邮件早于13:05模拟任务，不附上当日尚未发生的模拟成交，查看结果时以网站账本更新时间为准。

需要的 Secrets：`MAIL_USERNAME`、`MAIL_PASSWORD`、`MAIL_TO`，以及推荐的 `ACCOUNT_STATE_JSON`。Render任务触发仍使用 `CRON_SECRET`、`GITHUB_ACTIONS_TOKEN`。

## 数据与证据边界

- 基本面四维评分来自东方财富已披露财务指标；最终周度候选额外读取资产负债率、货币资金、应收和存货。
- 综合快讯用于风险词匹配，但未匹配不代表交易所公告已完整核验；页面保留该边界。
- 外盘、商品和地缘事件只形成基准/利好/利空情景，必须由A股板块趋势和个股相对强度确认。
- 止损价不是保证成交价；跳空、跌停、停牌和流动性不足可能扩大实际亏损。
- 做T默认关闭；只有已确认底仓、周趋势有效、未触发周熔断且已确认券商条件单时，才显示资格提示，系统仍不自动下单。

## 模拟仓

- 网站 `/api/paper` 只读公共模拟账本，真实账户与模拟账户完全隔离。
- 每交易日13:05由 `paper-trading.yml` 尝试运行；13:00–14:00以外、休市、行情过期均不补造成交。同一天最多记账一次；当日数据不齐的项目记录等待，次日再检查。
- `python paper_trading.py` 是同一入口。GitHub Actions为线上账本唯一写入方，并提交 `output/research/paper_trading.json`；服务重启后从公共快照恢复。手动按钮经管理密钥授权后请求工作流，不在Web进程内写账本。
- 5万元：一只周度主选，预留费用后尽可能满仓。这是用户指定的高风险仓位实验，明确覆盖原单股仓位/单笔风险限制；不绕过选股、价格、撤销、周亏损2%暂停开仓等条件。止盈后不补仓。
- 50万元：普通档总仓60%、单股20%、每笔初始风险0.6%。不使用真实账户固定300元风险额；每周两只主选的限制照常保留，现金也是有效状态。
- 卖出需完整当日上午个股/大盘/行业数据、上一交易日日K及5分钟内现价。T+1；止损和趋势失效优先。止盈以成交时固定R和原始股数计，两档累计卖出约1/3、2/3，整手向下取整，阶段只在成交后推进；直接达到2.5R时可累计兑现2/3。
- 跟踪止损取已完成日K的10日均线与近3日低点较低值，只上移，下一次检查生效。每天检查一次，不是盘中连续止损。
- 费用为明确的模型假设：双向滑点0.1%；佣金万三、最低5元；卖出附加税费万五。保守屏蔽涨跌幅限制附近成交，未模拟订单队列、流动性冲击或特殊上市日规则。
- 总资产含浮动盈亏及已扣费用；净值按模拟检查时点采样，缺价格时保留旧价并标注，因此不是收盘净值或实时回撤。两种目标均不是收益保证。
- 技术因子页面、API、定时任务、线上快照同步及邮件依赖已移除。旧 `quant_*.py` 和其测试仅保留为离线历史研究，网站不再调用。
