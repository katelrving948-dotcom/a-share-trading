# 基本面 + 上升趋势 + 回调企稳

实施版本：`fundamental-trend-pullback-v1`。本次为规则实现和功能验证，不代表已经取得策略收益或样本外回测结论。

## 不可绕过的三个条件

1. 基本面原始分、行业校准分都至少60分；板块分至少55分，财务风险未触发硬拦截。高技术分或单日涨幅不能抵消基本面不合格。
2. 使用已完成日K：MA20向上、MA20>MA60、价格>MA60、20日相对基准收益为正。价格短暂回到MA20附近不等同于趋势破坏。没有新买点不构成已有持仓的卖出理由。
3. 必须先发生计划形成之后的回调触及，再有后续日K企稳，不能在首次触及当天或确认当天成交。实际许可还需新鲜分时价、风险距离及账户检查。

## 市值范围与持仓计划

- 原代码市值下限是50亿元，调整为20亿元；邮件的500是扫描数量，与500亿元无关。
- 20至500亿元以下股票，行情快照成交额至少0.5亿元；较大市值沿用至少0.2亿元。这里是快照成交额，不是假称历史日均成交额。
- ST、北交所、价格和换手率筛选保留。科创板继续允许研究，仓位计算至少200股；账户是否具备交易权限仍由券商校验。
- 有限财务扫描、候选截断和日K扫描为中小市值保留约三分之一名额，之后仍需独立通过三条件。冻结股票优先保留数据跟踪，避免排行下降导致丢失回调状态。
- 中小市值的持仓观察期为3-10个交易日，较大市值为5-20个交易日；分别在买入后3/5个交易日复核是否恢复强势，破位提前退出。该时间是计划，不是涨幅预测，也不强制持有到期。
- 当前账户没有买入日期字段，所以只展示期限及复核规则，不编造“已持有几天”或具体卖出日期。

## 固定价格与状态转换

`config.PULLBACK` 集中定义初始参数，均待收益回测验证：

| 参数 | 初值 |
|---|---|
| 计划支撑区 | 形成时MA20 ± 0.5ATR14 |
| 最小回撤 | 形成时已知近10日高点 - 当日低点 ≥ 1ATR14 |
| 企稳 | 触及后的日K低点不低于最近触及日低点，收盘高于支撑上沿 |
| 最高买价 | 支撑上沿 + 0.5ATR14 |
| 失效价 | 形成时已知近10日低点 - 0.2ATR14 |
| 有效期 | 形成日之后5个完整交易日K，第5日收盘到期 |
| 价格风险距离 | 拟成交价到失效价占拟成交价的4%-7% |
| 前高空间 | （已知前高 - 拟成交价）÷（拟成交价 - 失效价）至少1.5 |

状态为等待回调、等待企稳、企稳已确认、失效、到期。同一计划的支撑、前高、ATR和失效价不会随报价上移或下移。重复预览重放形成日之后的已完成K线，结果一致；已撤销的周度名单不复活。

行情异常、当前日K未完成、缺乏同期基准、昨日K线未更新、非当日分时数据、时间戳缺失、行情超过5分钟或非交易时段均不能获得实时许可。午间邮件显示条件计划；开盘后需要重新复核。上一工作日检查在长假或个股停牌后可能保守阻断，待数据补齐才启用。

普通账户风险预算仍受原档位约束，并按净值0.6%封顶，避免小账户沿用300元造成风险占比过高。两只主选的现金预留合并计算。数量是目标持仓上限，不是额外买入数量。

## 兼容与生效

- 老周度名单保留股票身份；没有新版本回调字段时，以最新已完成日K创建新计划，等待形成后的触及与确认，不追溯制造买点。
- `freeze_weekly_plan` / `save_weekly_plan` 持久化新字段，既有每日邮件流程继续保存。公开预览仍不替用户下单，也不发送邮件。
- 新市值范围须在下一次基本面刷新后进入快照；已有快照不会凭空补出未扫描的股票。网站刷新按钮已改为全量合格池，邮件默认500只并保留中小市值扫描容量。
- 网页和邮件均展示回调价位、买点状态、市值及持仓观察期。旧日度突破触发不再获得日度入场通过。

## 验证与边界

功能测试覆盖触及不等于确认、完整日K限制、计划不漂移、次日限制、超价、破位、过期、缺失/陈旧行情、账户阻断、基本面不可抵消、市值与成交额、科创板最小数量和冻结名单撤销。

上线后仍需与原策略在相同股票池、退出规则和风险预算下比较1/3/5日最大不利波动、净收益、最大回撤、止损率、成交次数及错过机会比例。不得把合成数据测试称为盈利回测。

交易制度参考：[上交所交易规则（2026年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。普通A股T+1可卖、涨跌停、跳空和流动性限制可能导致实际成交与计划不一致；这里不自动执行委托。
